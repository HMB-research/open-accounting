# Historical Development Plans

The files in this directory are planning snapshots. They are useful for context,
but they are not the current source of truth for product status, verification
evidence, or remaining production gaps.

Use these current docs first:

- [Current Product Limits](../CURRENT_PRODUCT_LIMITS.md)
- [Development Status](../DEVELOPMENT_STATUS.md)
- [Use Case Coverage Matrix](../USE_CASE_COVERAGE.md)
- [Feature Mapping: Merit & SmartAccounts](../FEATURE_MAPPING_MERIT_SMARTACCOUNTS.md)

Older plans can overstate future intent, list work that has since landed, or
reference stale CI runs. When a plan is resumed, update the current docs above
after the implementation is verified instead of treating the old plan as
authoritative.
